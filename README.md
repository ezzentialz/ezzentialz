- ⚙️ I build **end-to-end automation**: Power Automate flows, SharePoint/M365 integrations, approval & email workflows, and Excel VBA tools
- 🤖 I design and deploy **AI agents** with the Claude API — document processing, OCR, PDF extraction, validation and email automation
- 🏗️ I set up our internal **AI agent infrastructure**: an agent registry, a reusable skill system, and a maturity model (L2 → L3 → L4) for taking agents from "chat assistant" to fully automated flow
- 🎓 Humanities background → self-taught builder. Proof that you can learn to think in systems from anywhere

### 🔧 How I work

```
Understand the business process
```

### 🚀 What I'm building

- 📄 **Document automation pipelines** — OCR + LLM to read, classify, rename and route PDFs (lab reports, invoices, debit/credit notes) into SharePoint
- ✅ **AI validation engines** — rule-based + LLM checks for contracts and product artwork compliance
- 📊 **Ops monitoring** — Python-generated daily digests of automation flow health
- 🔌 **MCP servers** — exposing internal business systems as tools for AI agents
- 💸 Currently exploring **cost-efficient AI** for production workflows (prompt optimization, batching, local models)
